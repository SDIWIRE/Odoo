Work Center Parallel Scheduling

Version 19.0.1.0.0  |  Category: Manufacturing

Adds a Number of Workers field to each work center so Odoo's MRP scheduler knows how many jobs can run simultaneously. When five workers each run an independent Manufacturing Order at the same time, the scheduler can now plan all five in parallel instead of queuing them one after another.

The Problem

Odoo's standard work center model assigns a single resource.resource record to each work center. The scheduler treats that resource as a single capacity unit: only one work order at a time. If your ASSEMBLY work center has five workers, Odoo will incorrectly queue work orders five times longer than reality.

The Solution

This module creates one resource.resource slot per worker, each with its own independent calendar and leave history. The patched scheduler scans all slots and assigns each incoming work order to the slot with the earliest free window — exactly the same mechanism Odoo uses internally, scaled to N workers.

⚙️ Native integration

Uses resource.resource and resource.calendar.leaves — no monkey-patching, no separate scheduler.

🔢 One field, zero complexity

Set Number of Workers and save. Slots are created, removed, and synced automatically.

📅 Calendar-aware

Respects working hours, public holidays, and any existing booked time when distributing work orders.

🔄 Live adjustable

Increase or decrease workers at any time. Existing planned work orders are not disturbed; future planning reflects the new count immediately.

Where to find it in the UI

  • Work center form → General Information tab → Number of Workers field (below Time Efficiency)
  • Work center form → Worker Slots tab → full list of resource slots with a Sync button
  • Manufacturing → Configuration → Work Center Workers → management list; edit all work centers in one screen
  • Work order form → Assigned Worker Slot field (read-only; set automatically by the planner)
Note: The module requires mrp_workorder (Manufacturing Work Orders, included in Odoo 19 Enterprise). After installation, open each work center, set the worker count, and click Save — slots are created immediately. Then use the standard MRP Plan button on any Manufacturing Order to see parallel scheduling in action.

Technical Notes

  • Model added: mrp.workcenter.worker.resource (junction between work center and its N resource slots)
  • Fields added to mrp.workcenter: number_of_workers, worker_resource_ids, worker_slot_count
  • Field added to mrp.workorder: worker_resource_id (which slot the planner chose)
  • Override: mrp.workorder._plan_workorder() — multi-slot search replaces the single-resource check when number_of_workers > 1
  • Uninstalling the module leaves work center data intact and restores standard single-resource planning
